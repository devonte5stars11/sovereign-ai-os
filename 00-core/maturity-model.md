# Maturity Model — Evaluating Progress Over Time

Use this to assess where the system is, and what the next level unlocks.

| Level | Goal                              | Signals you're here                                     |
| ----- | --------------------------------- | ------------------------------------------------------- |
| L1    | Personal assistant                | Single-user tasks, working vertical slice (Kernel MVP).|
| L2    | Multi-agent collaborator          | SoulVault profiles route work; multiple agents coordinate.|
| L3    | Autonomous research system        | Scheduled intelligence loops; knowledge pipeline runs unattended.|
| L4    | Product development studio        | Product Studio ships client SaaS; Creative Studio ships assets.|
| L5    | Enterprise operating system       | Multiple clients, isolated sandboxes, governance dashboards.|
| L6    | Self-improving knowledge platform | LDD closes the loop: evaluation → graph revision → promotion.|

## Current target (Phase 1)
Reach **L1 fully**, and demonstrate the LDD loop so L2 automation is trustworthy.
