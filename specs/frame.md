# SpecStack — Frame (Video & Visual Structure)

Standard Video Structure (Marketing):
1. Hook (0–3s) — pattern interrupt or clear result
2. Problem (3–8s) — specific pain the audience feels
3. Solution (8–20s) — what the AI system does
4. Proof / Mechanism (20–35s) — how it works simply
5. Offer + CTA (final 5–10s)

Visual Rules:
- One clear idea per shot
- Large readable text
- Cinematic lighting and motion when using Higgsfield
- Always end with a clear next step

Length Preference:
- 15–45 seconds for ads
- 60–90 seconds for explainer / authority content
