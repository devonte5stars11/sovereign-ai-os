# SpecStack — UI

Design Principles:
- Clarity over cleverness
- Strong visual hierarchy
- Generous spacing
- Mobile-first when relevant
- Premium but not fragile

Components:
- Clean cards
- Clear primary buttons
- Minimal form fields
- High-contrast CTAs

Landing Page Structure (default):
1. Hero (headline + subhead + primary CTA)
2. Problem section
3. Solution / How it works
4. Benefits / Outcomes
5. Social proof or logic
6. Offer / Pricing
7. Final CTA + FAQ

Always use SpecStack brand voice and visual direction.
